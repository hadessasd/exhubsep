ExamHub · Deploy kit

Upload to GitHub → host on Render

This guide walks you through the zip → GitHub repo → Render path. You only need a free Neon database key + Render env vars. Email/password login works without Google.

Download project ZIP Open ZIP → GitHub uploader Open GitHub New Repo Open Render

What you’ll create

  • GitHub repo — source code from the zip
  • Neon Postgres — free database (DATABASE_URL)
  • Render Web Service — live site (free tier sleeps when idle)

Step 1 — Create the GitHub repo

1
Open github.com/new
2
Repository name: examhub (or any name you like).
Visibility: Private recommended.
3
Click Create repository — leave it empty (no README needed if you upload the zip).
4
On the empty repo page: Add file → Upload files → drop everything from the unzipped folder (or use the zip upload if GitHub accepts it, then extract isn’t automatic — better to unzip first).
5
Commit message: Initial ExamHub deploy → Commit changes.
Your repo URL will look like:
https://github.com/YOUR_USERNAME/examhub
That is what Render connects to.

Step 2 — Get the Neon database key

1
Sign up at neon.tech (free).
2
New Project → name it examhub.
3
Dashboard → Connection string → copy URI (includes user, password, host, database).
4
Paste somewhere safe — this is DATABASE_URL. Keep ?sslmode=require if Neon shows it.

Step 3 — Connect repo on Render

1
Go to dashboard.render.com → sign in with GitHub.
2
New + → Web Service → connect the examhub repo.
3
Settings: Runtime: Node Build Command: npm ci --include=dev && npm run build:render Start Command: npm start (Or use the included render.yaml Blueprint: New → Blueprint → select repo.)
4
Environment variables (Environment tab): DATABASE_URL=postgresql://…from neon… BETTER_AUTH_URL=https://YOUR-SERVICE.onrender.com BETTER_AUTH_SECRET=paste-openssl-or-generate VITE_AUTH_ENABLED=true NITRO_PRESET=node-server NODE_ENV=production
5
Click Create Web Service / Deploy. First build takes a few minutes.
6
When live, open the Render URL. Sign up with email, or sign in as admin with minjunnios@gmail.com after creating that account.

Step 4 — Optional: custom domain

Render → your service → Settings → Custom Domains → add examhub.shop (or whatever you own) → point DNS as Render shows. Then set BETTER_AUTH_URL to https://examhub.shop and redeploy.

Git CLI alternative (instead of upload UI)

# unzip the project, then: cd examhub git init git add . git commit -m "Initial ExamHub" git branch -M main git remote add origin https://github.com/YOUR_USERNAME/examhub.git git push -u origin main

Create a Personal Access Token if GitHub asks for a password when pushing (use the token as the password).

Troubleshooting

  • Build fails on migrate — check DATABASE_URL is correct and Neon project is active.
  • Blank page — open Render logs; ensure start command is npm start and NITRO_PRESET=node-server.
  • Invalid origin on login — BETTER_AUTH_URL must exactly match the public HTTPS URL.
  • Free tier sleep — first visit after idle can take ~30–60s to wake.
